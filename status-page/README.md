# Status page indipendente

Artefatto statico pronto per un progetto di hosting separato da Vinea. Non è
considerato indipendente finché non viene pubblicato con account/progetto,
dominio e catena di deploy distinti dall'app principale.

Il contenuto si aggiorna manualmente durante un incidente. Il banner interno
può collegarlo tramite un URL HTTPS; nessun automatismo fragile dipende dalla
disponibilità dell'applicazione principale.
