# Candidate identificate — AI Skills Lab RECOVERY-001

Gli scanner sono output di SkillSpector `--no-llm` (credenziali rimosse, rete bloccata): un punteggio non è una prova di compromissione e i rilievi sono stati esaminati a mano dove indicato. Gli audit dei repository più ampi sono statici, in sola lettura, su cloni al commit indicato, con **copertura parziale** (triage mirato, non lettura integrale): vanno ripresi prima di qualunque adozione futura. Un audit statico non equivale a un benchmark pratico: nessuna candidata nuova è stata confrontata con prove riproducibili in questo ciclo (Taste e Impeccable restano quelle del Ciclo 2).

## Criteri applicati

Utilità concreta e distinta dalle skill presenti; licenza verificata da un file (non dal solo frontmatter); provenienza e commit immutabile; nessun segreto, nuovo MCP privilegiato, hook che aggiri le guardie o costo; compatibilità con Windows, Claude Code e profilo `vinea-coding` (Python e FFmpeg assenti, Docker presente); SKILL.md entro 600 righe per le esterne (300 per le interne) senza `allowed-tools`, `hooks` o iniezione di shell. Stati: INSTALLATA (nel repository e caricata dal profilo), RINVIATA (con condizione di sblocco), SCARTATA, BLOCCATA, NON RISOLTA, NON VERIFICATA, NON APPROFONDITA (solo metadati o lettura della fonte), NON PERTINENTE.
