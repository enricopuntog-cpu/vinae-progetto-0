## 6. Prestazioni di laboratorio (non sono Core Web Vitals reali)

Build di produzione locale, stack dedicato, Chromium, 5 ripetizioni, mediane, cache
fredda, caratteri da Google Fonts via Internet (variabilità non controllata).
Mobile = 375 px, CPU 4×, rete «Slow 4G» (1,6 Mbit/s, 150 ms). TBT approssimato dai
long task; «interazione» = massimo `event timing` di una sola interazione guidata,
**non** un INP reale. WebKit: API non disponibili, non misurato.

| Pagina | Desktop LCP ms | CLS | Mobile LCP ms | CLS | TBT~ ms (mobile) | JS KB (richieste) |
|---|---|---|---|---|---|---|
| home | 716 | 0,001 | 2980 | 0,001 | 183 | 305 (19) |
| accedi | 384 | 0,027 | 3108 | 0,063 | 157 | 296 (18) |
| esplora | 396 | 0,012 | 2416 | 0,021 | 207 | 322 (19) |
| annuncio | 504 | 0,001 | 2420 | 0,001 | 460 | 453 (23) |
| cantina | 680 | **0,759** | **5564** | 0,055 | 566 | 465 (25) |
